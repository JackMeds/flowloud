# Flowloud

Flowloud is an Edge and Chrome reading extension with system voices, opt-in browser models, a Windows local Qwen backend, and user-configured OpenAI-compatible TTS.

New installations use system voices. Page text stays local unless the user explicitly selects an online provider. There is no telemetry, advertising, or background collection.
