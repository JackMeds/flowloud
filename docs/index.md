# Flowloud / 流声

让网页自然地流动起来。Flowloud 是一款 Edge / Chrome 网页朗读扩展，支持系统语音、浏览器本地模型、Windows 本地 Qwen 与用户配置的 OpenAI 兼容在线 TTS。

[安装说明](install.md) · [隐私政策](privacy.md) · [支持](support.md) · [English](en/index.md)

## 产品原则

- 新安装默认使用系统语音，无需模型或账号。
- 网页正文默认在本机处理，无遥测、广告或后台收集。
- 页面导览只导航和朗读，不操作网页控件，也不替代读屏软件。
- 在线 TTS 仅向用户主动配置的服务发送待朗读文本。
