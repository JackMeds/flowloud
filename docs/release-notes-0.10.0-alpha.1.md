# 0.10.0-alpha.1

- 新增可见的文档与翻译工作台：当前网页、截图、粘贴文本、图片、PDF 页选择、OCR、分块翻译、编辑、复制、重试与朗读。
- 新增命名式 AI Profile，分别选择 OCR 和翻译服务；支持 OpenAI Chat、OpenAI Responses、Ollama 与 Flowloud Document V1，以及主流厂商预设。
- 数字 PDF 在本地提取文字；扫描页仅在用户确认后发送给所选服务。文档结果不持久化。
- 浏览器模型收敛为固定 revision 的 Kokoro v1.1 中英模型；权重/音色按需缓存，发布包只包含一套运行时。
- WebGPU 失败会显示原因和 WASM 回退状态。
- 新增豆包 TTS 原生协议适配器。
- 网关模型 ID、量化、模型文件和参考音频改为配置；支持 0.6B、1.7B 及服务端能够承载的更大模型。
- 设置升级到 Schema V6，保留既有 TTS 设置并迁移旧浏览器模型配置。
