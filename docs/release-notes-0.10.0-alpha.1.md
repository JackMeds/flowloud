# 0.10.0-alpha.1

- 新增可见的文档与翻译工作台：当前网页、截图、粘贴文本、图片、PDF 页选择、OCR、分块翻译、编辑、复制、重试与朗读。
- 新增命名式 AI Profile，分别选择 OCR 和翻译服务；支持 OpenAI Chat、OpenAI Responses、Ollama 与 Flowloud Document V1，以及主流厂商预设。
- 数字 PDF 在本地提取文字；扫描页仅在用户确认后发送给所选服务。文档结果不持久化。
- 浏览器模型收敛为固定 revision 的 Kokoro v1.1 中英模型；权重/音色按需缓存，发布包只包含一套运行时。
- 浏览器模型默认从魔搭社区（ModelScope）下载并支持最多 4 路 Range 分片续传；Hugging Face 仅保留为用户主动选择的手动备用来源。模型本体与 103 个音色分开缓存，默认只准备 4 个起始音色，其余音色可在独立设置页按需下载、修复或删除。
- 浏览器模型默认使用 WASM 兼容模式；WebGPU 仍可手动选择，初始化失败或返回削波/尖峰等异常 PCM 时会记录原因并回退，避免把电流声当成可用音频。
- Popup 的浏览器模型音色下拉框只展示已缓存且可播放的音色；旧的 fp16/q8 选择会迁移到已验证可发声的 fp32，合成校验会拒绝静音或明显失真的 PCM，并对正常输出施加有界增益。模型运行日志保留错误、隐藏已知的 Transformers.js 架构提示，并移除扩展页面无效的 modulepreload 警告。
- 新增豆包 TTS 原生协议适配器。
- 网关模型 ID、量化、模型文件和参考音频改为配置；支持 0.6B、1.7B 及服务端能够承载的更大模型。
- 设置升级到 Schema V7，保留既有 TTS 设置并迁移旧浏览器模型配置；旧的 WebGPU 默认会切换到 WASM 兼容模式。
