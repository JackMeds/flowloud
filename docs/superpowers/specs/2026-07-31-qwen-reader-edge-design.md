# Qwen 网页朗读 Edge 扩展设计

## 目标

交付一个可以直接加载到 Edge 的 Manifest V3 扩展，使用已经验证的本地
`qwentts.cpp` Vulkan 服务朗读论坛、小说和长文章。界面采用用户确认的
“方案 A：精致紧凑侧栏”，不再依赖先选择文字才能朗读。

## 使用方式

- 页面右下角常驻一个紫色 Qwen 悬浮球。
- 点击悬浮球打开右侧朗读侧栏；再次点击或点击关闭按钮收起。
- 点击主播放键后，扩展自动识别当前页面正文并从第一段开始朗读。
- Edge 工具栏图标与快捷键 `Alt+O` 也能打开或关闭侧栏。
- 页面中的当前段落会以柔和边框高亮，前进/后退按内容段落移动。

## 内容提取

### 生如夏花等 Flarum 论坛

优先从同源 Flarum API 读取主题全部楼层，包含尚未出现在当前 DOM 中的短回复。
API 不可用时回退到 `.Post`、`.Post-body`、`.PostUser` 等 DOM 结构。

每个楼层输出：

- 楼层编号；
- 作者稳定标识和显示名称；
- 是否为楼主；
- 清理后的正文；
- 对应页面元素（存在时），用于高亮和滚动定位。

清理时排除点赞、回复、编辑、举报、签名、徽章、时间轴、工具栏、隐藏元素、图片
替代文字和论坛插件控件。只要正文至少有两个可读字符，短回复也必须保留。

### 小说和普通长文

读取顺序为：

1. 用户当前选择的文本；
2. `article`、`main`、`[role=main]`、常见章节或正文容器；
3. 基于正文长度、链接密度和段落数量评分出的最佳容器。

从标题、段落、列表项和引用块生成朗读段落，过滤导航、页眉页脚、按钮、广告、
推荐、评论工具和浮动控件。正文按中文标点拆分为不超过 260 个字符的 TTS 块。

## 音色分配

默认预设为“楼主专属”：

- 楼主固定使用音色 A，且其他作者永不使用 A。
- 其他作者或发言轮次只从 B 及之后的回复音色池轮换。
- 在有两个以上回复音色时，相邻的不同回复者不会使用同一音色。
- 楼主后续所有楼层继续使用 A，不因楼层变化重新分配。

另提供：

- “作者稳定”：每个回复作者在当前主题中稳定映射到 B 及之后的音色；
- “顺序轮换”：每个非楼主楼层按 B、C、B、C……轮换。

切换音色只改变 `/v1/audio/speech` 请求中的 `voice`，不会重启或重新加载模型。

## 播放链

- 扩展后台向 `http://127.0.0.1:7811` 发请求。
- 合成格式固定为 WAV，模型名为 `qwen3-tts-1.7b-base`。
- 首块生成后立即播放；播放期间预取下一块，减少段落间空白。
- 暂停保留当前音频位置；停止会取消后台请求并清空预取队列。
- 冷启动或错误必须显示明确状态，不能无限转圈。
- 模型闲置释放由现有托盘网关负责，扩展地址不变。

## 音色库与录音

侧栏“音色库”标签展示服务端音色及本地保存的录音音色。新增音色在扩展自有的
“音色录制室”页面完成：

- 输入音色名；
- 录制 5～15 秒麦克风音频；
- 显示计时并可试听；
- 转换为 24 kHz、单声道、16-bit PCM WAV；
- 保存到 `chrome.storage.local`；
- POST 到 `/v1/audio/voices` 注册；
- 下次模型冷启动后，扩展自动补注册缺失的本地音色。

本地音色不上传互联网。

## 视觉与交互

- 使用 Shadow DOM 隔离网站样式。
- 侧栏宽度桌面端 376 px；窄屏使用不超过视口 94% 的抽屉。
- 主色为紫色渐变，状态色为绿色，卡片采用浅紫灰底。
- 顶部标签为“正在朗读 / 作者配音 / 音色库”。
- 播放和暂停使用 CSS 图形或 SVG，不使用字符 `Ⅱ`。
- 页面刷新后保留面板位置、预设和音色选择。
- 尊重 `prefers-reduced-motion`。

## 权限与安全

- 仅使用 `storage`、`activeTab`、`scripting`、`tabs` 与麦克风所需权限。
- 本地 TTS 主机权限限定为 `http://127.0.0.1/*`。
- 扩展不执行远程脚本，不使用 `eval`，不上传网页正文或录音。
- 网页正文只发给本机回环接口。

## 验收

1. 生如夏花主题能识别楼主和所有已返回楼层，短回复不丢失。
2. 点赞、回复按钮、签名和插件提示不进入朗读文本。
3. 楼主始终使用 A，任何其他作者都不使用 A。
4. B/C 音色能够逐段切换，模型进程 PID 不变化。
5. 小说/长文无需选择文字即可识别主要正文。
6. 悬浮球、侧栏、暂停、前进、后退、停止均可操作。
7. 音色录制、试听、保存、注册和冷启动补注册可用。
8. 本地服务不可用时在 60 秒内给出中文错误，不无限转圈。
9. Edge 可以直接以“加载解压缩的扩展”方式加载交付目录。
