# Qwen Reader 视觉与跟随体验设计

## 目标

- 将页面右下角入口改为 40px 圆形按钮，使用新生成的“极光声波”图标。
- 当前朗读段落采用紫蓝极光下划线与轻微文字光晕，不再显示生硬描边框。
- 自动跟随时把当前段落平滑定位到视口中央；用户主动滚动后继续尊重现有暂停跟随机制。
- 扩展样式加载完成前完全隐藏 UI，消除网页刷新时扩展白字和未样式化内容闪现。
- 同一图标同时用于扩展清单图标和页面悬浮按钮。
- 侧栏宽度可通过左边缘拖动或面板内滑杆调整，并持久保存。
- 提供“网页点读”开关；开启后点击已识别正文，直接从相应段落开始朗读。

## 设计细节

- 悬浮按钮固定为圆形，默认 40×40px；白色半透明底、细边框和轻阴影，内部图标 32px。
- 高亮使用不改变页面排版的背景渐变下划线、柔和外发光和文字边缘光，不强制修改目标元素定位。
- 每个新的朗读定位点只触发一次 `scrollIntoView({ block: "center" })`；手动滚动抑制期间不抢夺滚动。
- Shadow DOM 宿主创建时先以内联 `display:none!important` 隐藏；外部 CSS 的 `load` 事件后显示，`error` 时移除宿主并记录错误。
- 图标资产输出 16/32/48/128/512 像素透明 PNG，写入扩展包并在 Manifest V3 中声明。
- 侧栏宽度限制在 300～640px 且不超过当前视口；链接、按钮、输入框等交互元素不触发网页点读。

## 验收

- 按钮始终为圆形且尺寸为 40px。
- 页面刷新无扩展未样式化内容闪烁。
- 自动跟随定位到中央；用户滚动时不会被立即抢回。
- 新图标在按钮和 Edge 扩展管理页均正确显示。
- 调宽后刷新仍保留；网页点读能定位正确队列项且不会拦截页面原有交互控件。
- Node 回归测试、浏览器 UI harness 与扩展打包均通过。
