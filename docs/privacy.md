# 隐私政策

生效日期：2026-08-21。

Flowloud 不含遥测、广告或后台数据收集。网页正文默认在设备上提取和处理；系统语音与浏览器模型不会上传正文。只有用户主动选择 OpenAI 兼容在线 TTS 时，待朗读文本才会发送给用户配置的服务，其处理受该服务政策约束。

浏览器模型仅在明确确认后从 Hugging Face 下载权重；下载不包含网页正文。API Key 默认保存在 `chrome.storage.session`，浏览器会话结束即清除；只有用户勾选“记住密钥”才保存在本机扩展存储，绝不写入日志、同步存储或设置导出。

音频导入默认跳过在线识别。用户明确允许后，提取的 5–15 秒片段才会发送给 Microsoft Edge 在线语音服务识别台词。用户可以始终手动填写或留空。
