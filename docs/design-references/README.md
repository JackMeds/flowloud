# Flowloud 前端恢复基线

## 已选视觉目标

- 参考图：`flowloud-popup-blue-white-v1.png`
- 方向：中性蓝白，不引入装饰性渐变或品牌紫色。
- 优先级：信息层级与可用布局优先于视觉装饰。

## 固定交互契约

### 网页悬浮播放器

- 默认显示为完整可见的 52 × 52 px 悬浮球，不允许半隐藏到视口外。
- 单击悬浮球只负责展开，不在收起态复用为播放/暂停按钮。
- 展开态必须同时提供上一句、播放/暂停、下一句、跟随当前句和收起控件。
- 拖动、边缘吸附、播放控制必须使用不同的命中区域，不能相互抢事件。

### 扩展弹窗

- 顶部播放器保持稳定，不因设置内容增长而被挤出首屏。
- 主导航固定为：`朗读 / 本页音色 / 设置`。
- 主播放按钮位于运输控制中央，上一句与下一句分别位于两侧。
- 每个面板独立滚动；刷新播放状态时保留当前标签、焦点和滚动位置。

### 可靠性

- 暂停/继续请求必须有明确成功或结构化失败结果，最多等待 3 秒，不允许无限静默重试。
- 当前朗读位置必须依赖稳定段落身份与源位置，不能只用重复文本或当前屏幕几何位置猜测。

## 发布闸门

1. 恢复版：原生 MV3 代码完成上述契约、交互回归和真实站点验证。
2. 迁移版：WXT + React Aria Components + Storybook 完成后，再重复同一套回归；两个版本均验证 Chrome 与 Edge。
