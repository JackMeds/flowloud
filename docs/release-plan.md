# Flowloud / 流声 1.0 发布实施与放行清单

本文档补充公开发布总计划，作为 Beta 到 1.0 的唯一放行清单。Manifest 使用纯数字 `version`；带预发布标签的展示版本写入 `version_name`。

## 架构约束

- `SpeechProvider` 只声明能力和创建合成工作；`SpeechSession` 统一生命周期、来源标签页、暂停、恢复、取消和事件；`ModelManager` 独立负责下载、配额、校验、缓存与删除。
- 系统语音走 `chrome.tts`，精确边界是按 voice 能力提供的增强项，不作强保证。
- 浏览器模型运行库和 WASM 全部随扩展打包。内置模型固定 commit revision；自定义模型标记为实验性且同样必须固定 commit。禁止远程 JS、`trust_remote_code`、自定义加载器和非 Hugging Face 模型主机。
- 本地网关仅监听 `127.0.0.1:7811`，语音接口同时验证随机 Bearer 客户端令牌、扩展请求头和扩展 Origin；客户端令牌不得转发给后端。
- 在线密钥默认只存 `storage.session`；本地持久化必须由用户明确选择。所有秘密存储限制为 `TRUSTED_CONTEXTS`，不得进入设置导出、日志或错误详情。

## 分阶段范围

### `0.9.0-beta.1`

- Chrome Private / Trusted Testers；Edge Hidden 仅用于降低可发现性，不视为访问控制。
- 验证系统语音首次即用、正文朗读、页面导览、四 Provider 切换、旧设置迁移和权限撤销。
- 浏览器模型只开放两个固定白名单；自定义仓库保留实验性标识。
- Windows 便携包不捆绑模型，下载器执行断点续传与 SHA-256 校验。

### Release Candidate

- Chrome 可切换 Unlisted；Edge 继续受控发送链接。
- 修复 Beta 阻断问题，冻结权限、隐私文案、模型清单和依赖版本。
- 完成 NVDA、400% 缩放、强制颜色、减少动效、键盘顺序和固定元素冲突人工验收。

### `1.0.0`

- Edge 与 Chrome 各完成一次干净环境关键流程。
- 商店 ZIP、哈希、隐私披露、第三方 notices、双语商店资料一致。
- 无 P0/P1 安全问题、无阻断级无障碍问题、无密钥或模型权重进入发布包。

## 性能与稳定性门槛

- 安装后系统语音不创建模型运行时，也不下载任何内容。
- Popup 的常用操作在正常机器上不等待模型扫描；长任务必须显示进度且可取消。
- 页面语义快照不依赖当前 viewport，忽略未渲染内容；无名称控件保留并使用“未命名按钮/输入框”等安全回退名称。
- 浏览器模型下载前显示预计大小、许可、设备支持和存储空间；WebGPU 失败时按设置回退 WASM。
- 来源标签页关闭时清理该页会话；Popup 关闭不终止仍有效的朗读。

## 发布前必须人工完成

- NVDA 核心流程与双浏览器商店上传验证。
- Windows 无 Vulkan、低磁盘空间、模型校验失败、完全卸载测试。
- Windows 可执行文件代码签名与签名验证；若 Beta 尚未签名，下载页必须明确提示。
- 真实在线 TTS、真实浏览器模型下载和真实 qwentts.cpp 固定版本端到端验证。
- 执行完整 Git 历史审计；发现密钥时先轮换，再经明确授权重写历史。
