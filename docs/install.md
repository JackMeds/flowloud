# 安装与 Beta

`0.10.0-alpha.1` 首先通过 Chrome Private（Trusted Testers）和受控名单分发；候选版再切换为 Unlisted。Edge Hidden 只降低可发现性，不作为访问控制，因此下载链接仅发送给已登记测试者。商店包是独立 ZIP，并附 SHA-256。Windows 本地 Qwen 为可选便携包；扩展本身跨平台。

安装后刷新已经打开的网页即可使用。Flowloud 的网页内容脚本会在普通 HTTP/HTTPS 页面自动运行；开启“显示悬浮播放器”后，悬浮球会在可识别正文的网页自动出现，无需为每个网站重复授权。浏览器内部页面、扩展商店页面以及用户在浏览器扩展设置中明确禁止访问的网站不支持注入。
